# Learn to Read a Clock

An interactive web app that helps 5-year-olds learn to read analog clocks. No build tools required - just open index.html in any browser!

## Features
- Interactive analog clock with hour and minute hands
- Multiple choice questions that increase in difficulty
- Colorful animations and confetti when answers are correct
- Dark mode / light mode toggle
- Sound effects and visual feedback
- Progressive difficulty: starts with 15-minute increments, then moves to 5-minute increments

## Audio
The app uses Web Audio API to generate sounds if no sound files are provided. For better sound effects, add your own MP3 files:
- assets/correct.mp3 - a cheerful sound when answer is correct
- assets/wrong.mp3 - a tone when answer is wrong
- assets/pop.mp3 - a popping sound for confetti

## Usage
1. Simply open index.html in any browser
2. The app will work on both desktop and mobile devices
3. Click/tap the correct time shown on the clock
4. After 3 correct answers, the difficulty increases
